# Code of Conduct

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our pledge

We — maintainer and contributors — commit to making participation in this project a harassment-free experience for everyone, regardless of background, identity, experience, or technology preference.

## Our standards

**Encouraged:** showing empathy toward other community members, accepting constructive feedback gracefully, focusing on what is best for the project and the broader security community, attributing prior work, citing sources.

**Unacceptable:** harassment, personal or political attacks, publishing others' private information, sexualised language or imagery, weaponising security issues for blackmail or extortion, using this project's name to promote unlawful intrusion.

## Scope

This Code of Conduct applies in all project spaces (issues, PRs, discussions, commits) and in public spaces when an individual is officially representing the project (talks, social media posts, conferences).

## Enforcement

Report unacceptable behaviour to **yassirzahidi8@gmail.com**. All reports are reviewed within 7 days. Maintainers may take any action they deem appropriate, including warnings, temporary or permanent bans from project spaces.
